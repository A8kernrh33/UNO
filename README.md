# UNO — Tabletop Edition

A polished, responsive browser UNO game built as a single self-contained HTML app.

## Included

- Classic 108-card UNO deck
- 2–4 player games with built-in bots
- Easy / Smart / Sharp bot difficulty
- Color, number, and action matching
- Skip, Reverse, Draw Two, Wild, and Wild Draw Four
- Optional draw-card stacking rule
- UNO call button
- Automatic deck reshuffling
- Wild-color selection UI
- Round scoring
- Live player turn indicators and game feed
- Responsive mobile layout
- Dark glassmorphism tabletop UI with animations
- No dependencies, build step, or backend required

## Run

Open `index.html` in a browser.

For GitHub Pages, enable Pages for the repository and use the `main` branch as the source. The site is then served directly from `index.html`.
